# Pre-refactor baseline v1

This directory preserves the small, reviewable Phase 0 audit records for Git
commit `d2139c63a01e5506f190c03da2db5cdc2e79d495`.

It intentionally contains no raw orders, CSV/GPKG/Parquet/NPZ data products,
matrices, Golden payloads, or reproduction-release assets. Paths and hashes may
refer to external or ignored local data without copying those files into Git.

The original generated copies remain under
`outputs/refactor-validation/pre-refactor/`, which is ignored and disposable.
